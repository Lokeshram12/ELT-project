# ELT-project

## Motivation

This project demonstrates an ELT (Extract, Load, Transform) pipeline using the Netflix dataset from Kaggle. It is designed to show how raw data can be ingested, stored, and transformed for analysis.

## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Lokeshram12/ELT-project.git
   cd ELT-project
   ```
2. Install any required dependencies (if applicable).
3. Run the notebook or scripts to load and transform the dataset.

## Usage

- Open `sample.ipynb` to explore the ELT workflow and data analysis steps.
- Use `netflix_titles.csv` as the source dataset for extraction and transformation.
- Update or extend the pipeline as needed for your own ELT experiments.
